# 데이터 세트 구조 
폴더 구조는 0~9, 10~19 와 같이 나위어져 있음   
총 100개의 폴더가 있었음

0~9 폴더를 클릭할 경우 000, 001 ... 009 순으로 폴더 구성
000 폴더를 클릭할 경우 movie, picture 폴더 구성
movie 파일을 클릭할 경우 350개에 가까운 영상 파일이 있었음

폴더마다 파일이 살짝씩 빠진게 있었음   
예를들어 000 폴더에는 24, 30번 파일이 빠져있고,
0001 폴더는 1~5번 파일이 없는 등 불규칙 하였음  

라벨링은 아래와 같이 파일명에 적힌 숫자로 해당 감정 상태를 
텍스트로만 적혀있었음 

1~50 : 행복(Happiness)   
51~100 : 놀람(Surprise)   
101~150 : 무 감정(Neutral)   
151~200 : 공포(Fear)   
201~250 : 역겨움, 혐오(Disgust)   
251~300 : 화남(Anger)   
301~350 : 슬픔(Sadness)

### 1) 16 khz 리샘플링

사람의 대역폭은 보통 8khz 이하 범위 안에 있음 하지만 나이퀴스트 정리를 사용해서 __16khz__사용

__나이퀴스트 정리?__   
아날로그 -> 디지털 신호로 변환시 신호의 포함된 최고 주파수의 2배 이상으로 샘플링 해야 원래 신호를 완벽하게 복원할 수 있다는 정리

# 이미지 전처리

### 1) 데이터 셋 기준 평균, 표준편차로 정규화
-> 음성 스펙트로그램(Grayscale)은 분포가 표준화된 이미지와 다름   
-> 기존 ImageNet 평균/표준편차(0.485, 0.456, 0.406 …)를 쓰면 내 데이터랑 분포가 다를 수 있음.   
-> 그래서 직접 mean/std를 구해서 맞춰주는 게 더 안정적이었음

### 2) 사진 빈 영역 잘라내기 
-> 입력 스펙트로그램에 불필요한 테두리가 포함될 수 있다.
-> 일정한 margin(여백)을 잘라내어, 모델이 주요 음성 패턴에 집중할 수 있도록 한다. 

### 3) 가로(시간) 방향띠 마스킹
-> 스펙트로그램의 **가로 방향 일부(시간 구간)**을 가려서, 발화 중 특정 순간 정보가 사라진 상황을 흉내 낸다.   
-> 이는 발화 끊김·잡음 등 시간적 결손 상황에도 강인한 모델을 만들기 위한 SpecAugment 기법이다.

### 4) 세로(주파수) 방향띠 마스킹
-> 스펙트로그램의 **세로 방향 일부(주파수 대역)**을 가려서, 특정 음역대가 손실된 상황을 흉내 낸다.   
-> 이는 마이크 특성, 잡음, 특정 주파수 손실 등에 대비해 모델이 더 일반화된 특성을 학습하도록 돕는다.

### 5) 최대 평행이동(가로,세로) 비율 = 0.02   
-> 멜스펙트로그램은 발화 정렬에 따라 미세한 위치 차이가 존재한다.
-> 오디오 멜스펙트럼은 정렬이 미묘하게 달라질 수 있음, 살짝 흔들어서 모델이 덜 민감하게 세팅   
-> 위 설정을 전체 학습 샘플의 50%만 적용 (원본 패턴이 사라짐 방지)   

### 6) 일부 영역 가리기   
-> 전체 학습 샘플의 25% 적용해서 과도한 왜곡 방지   
-> 이미지 전체의 2 ~ 8 % 랜덤하게 가린다.    
-> 지운 부분을 검은색으로 채움 (검은색은 즉 무음이라는 뜻 -> 음성 공백으로 처리)

# 심리학을 근거로 한 지표 설정

전체 7개의 감정으로 분류했고 단순 7개로 나눠서 최대 가중치를 계산하면 
각 0.142....가 나옵니다.

우울증은 단순한 감정으로 추측할 수 없습니다. 
그래서 DSM-5 및 ICD-10 와 같은 정신질환 진단 분류체계를 참고해서 가중치를 설정했고 계산식을 만들었습니다.

### 1) 📘 DSM-5 (미국정신의학회)의 우울증 진단 기준
__9가지 증상 중 최소 5개 이상, 2주 이상 지속시 우울증__

반드시 포함되어야 하는 핵심 증상 2가지:
- 지속적인 슬픔(우울한 기분)
- 흥미나 즐거움의 현저한 감소(Anhedonia)

즉, 슬픔 및 무감정이 진단의 필수적 기준 중 하나로 강조됩니다.

### 2) 📗 ICD-10 (세계보건기구)의 우울증 진단 기준

__핵심 증상 3가지 중 2개 이상 2주 이상 지속__

핵심 증상 3가지:
- 지속적인 슬픔(우울한 기분)
- 흥미와 즐거움의 상실(Anhedonia)
- 피로·활력 감소

즉, 여기도 우울한 기분(슬픔) 이 핵심 증상으로 반드시 고려되어야 합니다.

### 3) DSM-5 , ICD-10 의 공통점

모델 학습 결과로 추출할 수 있는 감정 중 슬픔, 무감정 2가지를 포함하고 있습니다.

### 4) 중간 계산식

각 최대 가중치의 비율을 조정했습니다.    
슬픔이 1순위, 무감정이 2순위로 전체 감정중 최대 70%의 비중을 차지해야했습니다. 

그리고 심리학에서 우울증에 정의는 
**정서 균형 이론** 에서 찾을 수 있었습니다.

__정서 균형 이론 (Positive vs. Negative Affect Balance)__
- 우울은 단순히 슬픔이 강하다만으로 설명되지 않습니다.
- 핵심은 긍정적 정서가 부족하고 + 부정적 정서가 우세하다는 "균형의 붕괴" 입니다.

그래서 단순히 슬픔과 무감정이 높다고 해서 우울로 판단하기 어려웠고   
긍정의 감정도 고려해서 부정의 감정과 비교로 정서 균형이 깨지지 않았는지 판단할 필요가 있었습니다.

### 5) 최종 계산식
![최종계산](/jin_sup/result_exp.png)

분자 = 부정적 정서 가중합   
분모 = 전체 정서 중 긍정 정서(POS) 를 포함

즉, 단순히 “슬픔이 크면 우울”이 아니라   
👉 “부정적 정서가 크고, 동시에 긍정 정서가 적어야 우울”이라는 임상적 현실을 반영 했습니다.
